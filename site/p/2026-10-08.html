要闻与解析

10年期美债盘中升至5.36%，24年来最高；纪要显示多数官员认为年底前还要再加息

周三（10月7日）早盘，10年期美债收益率一度升到5.36%，是2002年4月以来最高；30年期盘中到5.73%。午间10年期国债拍卖结果出来后，收益率掉头回落，收在5.28%附近，全天几乎持平。这场390亿美元的拍卖需求很强：投标倍数2.77，是2016年以来最高；一级交易商只被分到约2.5%，说明真实买家把货接走了（Babypips 收盘综述、雅虎财经）。

下午两点（上海时间周四凌晨两点）公布的9月会议纪要，确认了加息的方向没变：9月那次加息25个基点是全票通过，多数与会者认为“到年底前再加息一次很可能是合适的”，同时强调每次会议“保持开放”、看数据决定。据 FXStreet 摘录，几乎所有人都认为通胀风险偏向上行，还有几位官员提醒，AI 数据中心的建设热潮最终可能让总需求跑到供给前面（FXStreet）。利率期货给10月28日加息的概率约17%—25%，但已经计入年底前加一次。

为什么拍卖比纪要更重要：过去一个月长端收益率猛涨，市场最怕的是“没人买美债”。这次拍卖说明，5.3%的收益率对买家有足够吸引力，供给恐慌暂时缓解。但美元指数涨了0.4%到102.3附近，黄金跌1.2%，美股三大指数小幅收跌，资金仍在往“高息美元资产”挪。

对币市：BTC 当天跌约2.6%，到8.34万美元附近，美股早盘时一度跌破8.3万。CoinGlass 数据显示全市场约5.5亿美元仓位被强平，其中多头约4.8亿美元（FXStreet 引 CoinGlass）。逻辑链是：长端收益率创新高 → 美元走强 → 持有不生息资产的机会成本上升 → 杠杆多头被挤出。收益率回落之后 BTC 没有跟着反弹，说明这次下跌里杠杆出清占了大头。

下一步看什么：今晚（上海时间周五01:00）的30年期国债拍卖；10月14日20:30公布的美国9月 CPI。

也门战火烧进沙特：胡塞武装袭击沙特机场、警告航空公司，海湾原油的红海出口也不安全了

据 CBS 新闻的实时报道，沙特支持的也门政府10月4日宣布要收复胡塞武装控制的全部地区，联军出动约100架次战机打击荷台达，也门政府军宣称已控制曼德海峡和穆哈港，胡塞方面否认失地。胡塞武装随即反击：10月5日沙特民航局确认南部吉赞（阿卜杜拉国王机场）和纳季兰两座机场遭袭，三人轻伤；胡塞还警告航空公司不要使用沙特领空（麦加、麦地那除外）。10月7日凌晨，联军称在利雅得以北拦截了一枚导弹。土耳其和巴基斯坦表示将按新的防务安排向沙特快速派兵（CBS 新闻）。双方的战况说法都无法独立核实。

为什么重要：沙特绕开霍尔木兹海峡的办法，是用东西输油管把原油送到红海边的延布港出口。这条管道9月11日到22日停过一次，10月4日到5日又被报道在胡赖斯遭袭。如果红海南口的曼德海峡和沙特本土也进入战区，海湾原油的两条出路就同时承压。霍尔木兹那边，英国海事机构本月已记录到九起袭船，波斯湾到中国的油轮运费创下每天130万美元的纪录（10 Things 综述）。布伦特原油周三重回每桶101—102美元；沙特阿美首席执行官说全球库存“薄得吓人”。

对币市：油价是这两个月“通胀 → 加息 → 长端收益率”链条的起点。红海风险让油价很难像市场希望的那样回落，美联储年底再加息的理由就多一条。

下一步看什么：东西输油管和延布港的实际出口量；胡塞是否真的攻击民航航班。

中国9月末外汇储备降至3.4万亿美元，央行连续第23个月增持黄金

国家外汇管理局10月7日公布，9月末外汇储备34003亿美元，比8月末减少381亿美元，降幅1.11%。外汇局的解释是：美元指数上涨，全球主要金融资产价格总体下跌，汇率折算和资产价格变化共同导致规模下降。同日央行公布，9月末黄金储备7747万盎司，比上月增加74万盎司，已连续23个月增持（新浪财经、光明网）。

外储下降主要是“账面”原因，不是资金外流：外储里有大量非美元资产和债券，9月美元升值、美债价格因收益率飙升而下跌，折成美元就少了。这和今天第一条是同一件事的两面。值得看的是黄金：74万盎司按每盎司约4100美元算，约30亿美元。在美债价格下跌、地缘冲突不断的时候继续买金，说明央行在把储备从美元资产里慢慢分散出去。

对币市：“央行买金、去美元化”是比特币“数字黄金”叙事的重要支撑。但要分清：央行买的是黄金，不是比特币；同样是避险资产，黄金过去一个月涨到4100美元上方，BTC 却在8.3万到8.7万美元之间来回，两者并不总是同向。

下一步看什么：10月中旬公布的9月 CPI、PPI 和金融数据；今天 A 股节后开市，美元走强时人民币汇率的表现。

AI 降价战升级：Anthropic 小模型 Haiku 5.5 每百万 token 0.1美元；ChatGPT 免费用户今天起用 GPT-6

Anthropic 10月7日发布 Claude Haiku 5.5：提示词在10万 token 以内时，输入每百万 token 0.10美元、输出0.50美元，是上一代 Haiku 4.5 的十分之一，和 OpenAI 最便宜的 GPT-6 Luna 同价；超过10万 token，整次请求按五倍价格计。官方说约九成的 Haiku 4.5 请求在10万 token 以内，算上新分词器会多切出一些 token，实际工作量成本约降75%。同时，中端的 Sonnet 5.5 缓存读取价格从每百万0.20美元降到0.10美元（VentureBeat、Claude 官方价格页）。同一天，OpenAI 把 ChatGPT 的对话模型换成 GPT-6：Plus 及以上用 GPT-6 Sol，免费和 Go 用户用 GPT-6 Luna，10月8日起推送；回答里可以直接出现图表、按钮、表单和小计算器，官方叫“Intelligent UI”（OpenAI）。

为什么重要：一个月前“便宜”和“好用”还要二选一。按 Anthropic 自己公布的测试，Haiku 5.5 在电脑操作测试 OSWorld 2.1 上得分72.4%，上一代只有15.7%，GPT-6 Luna 是48.9%。小模型的能力抬上来、价格打下去，很多原来只能用中端模型的活，现在用小模型就能做。但细节要看清：有开发者实测新分词器对同样文字多切出约30%的 token；开到高推理强度时，思考过程也按输出价计费，最贵的跑法可能比 Sonnet 5.5 还贵（DEV 社区）。跑分都是厂商自己报的，还没有独立结果。

对 AI 方向：做产品的话，批量摘要、分类、信息抽取这类“量大活轻”的环节，成本又降了一个数量级，值得重算一遍账。做内容的话，ChatGPT 回答从“一段文字”变成“一个可以点的小界面”，教程和测评类内容要跟着更新。两者在大陆都需要海外账户。

下一步看什么：独立评测机构对 Haiku 5.5 的实测；免费用户用上 GPT-6 后的额度限制。

主流大模型怎么选：先问任务，再看价格和门槛

昨天一天里，两家公司各做了一件事。Anthropic 发布 Haiku 5.5，每百万 token 输入0.1美元；OpenAI 宣布 ChatGPT 的免费用户今天起也能用 GPT-6。再加上上个月的 Opus 5.5、GPT-6.1 Sol，国内的 DeepSeek V4.1、Kimi K3、通义千问 Qwen3.7，光是叫得出名字的主力模型就有二三十个。

很多人选模型的方式是看排行榜：谁分高用谁。这一讲换个问法：不问“哪个最强”，而问“我这件事需要多强、能花多少钱、在哪能用”。问对了，你会发现大部分时候用不着最强的那个，而最强的那个也不是每次都最合适。

本讲的价格和产品信息截至2026年10月8日，来自各家官方价格页和发布说明；第三方整理的数据会注明。

一、四个问题，先于任何排行榜

1. 这件事要多强？ 把任务分三档。轻活：翻译、摘要、分类、改格式、从文本里抽字段，小模型就够。中活：写一篇像样的文章、读一份合同找问题、写一个几百行的功能，中端模型最划算。重活：跨几十个文件的代码改造、几小时的自主任务、需要长链条推理的研究，才值得上旗舰。

2. 能花多少钱？ 自己用，看订阅；做产品，看 API 的 token 价。两者是两套账，后面分开算。

3. 要读多长的东西、要不要看图听声？ 上下文窗口决定一次能塞进多少材料；多模态决定能不能直接丢给它截图、PDF、视频。

4. 在哪能用？ 对在中国大陆的人，这一条常常最先排除选项：账号、网络、支付、合规，任何一环卡住，再好的模型也用不上。

从表里能读出三件事。

第一，同一家的档位差很大，跨家的同档反而接近。 Sonnet 5.5 和 GPT-6.1 Sol 同价，Haiku 5.5 和 GPT-6 Luna 同价，旗舰都是10/50。价格接近时，比的是在你的任务上谁做得好、谁的工具链顺手。

第二，“便宜”有附加条件。 Haiku 5.5 超过10万 token 价格乘五；DeepSeek 分高峰和闲时；Gemini Flash 的价格是限时的。看价格表要看脚注。

第三，各家的强项不一样。 按各家公开的定位和多数开发者的使用经验：Claude 在编程、长时间自主任务和写作上口碑最好；OpenAI 的产品生态最完整，ChatGPT 每周用户约12亿，图像、语音、Intelligent UI 这些功能最全；谷歌的强项是长上下文、视频理解和与 Gmail、文档、YouTube 的整合；DeepSeek 和国产模型的优势是价格、中文语料和在国内的可用性，开放权重还能自己部署。

写代码、改项目 主力：Claude Opus 5.5、GPT-6.1 Sol（在 Codex 里） 简单脚本用 Sonnet 5.5 就够
读一本书、一堆 PDF、一段视频 Gemini 3.1 Pro 或 3.8 Flash Claude 4.6 以后的模型 100万上下文按标准价计
批量摘要、分类、抽取字段 轻量：Haiku 5.5、GPT-6 Luna、DeepSeek V4.1 Flash（闲时） 先抽样比准确率
给国内用户做产品 DeepSeek、通义千问、智谱 GLM 的国内 API 要了解生成式 AI 服务备案
最难的研究和推理 GPT-6 Astra、Claude Fable 5.1 先确认中端真的做不了

为什么编程先推 Claude 和 GPT-6.1 Sol：看 Anthropic 公布的 Terminal-Bench 4.0（在命令行里自主完成编程任务），Sonnet 5.5 是70.6%，Haiku 5.5 在最高推理强度下39.2%、默认强度约20%。小模型便宜十几倍，但在要连续动手几十步的任务上，差距很明显。这正是“按任务分档”的意义：同一个产品里，前台理解用户意图用小模型，真正动手写代码交给大模型。

四、动手：做一次你自己的盲测

排行榜测的是别人的题。最可靠的选模型办法，是用你自己的五道题测一次。一个晚上就能做完：

  1. 出题。 从你过去一个月真实做过的事里挑五件，覆盖你最常用的场景。比如：把一篇英文长文压成300字中文摘要；给一段交易复盘找逻辑漏洞；写一个把 CSV 转成图表的 Python 脚本；为一期视频写开头30秒脚本；从一份财报里抽出十个数字。每道题写成完整的提示词，附上材料。
  2. 选三个候选。 一个你常用的，一个同档的竞争者，一个便宜一档的。比如 Claude Sonnet 5.5、GPT-6.1 Sol、DeepSeek V4.1 Flash。
  3. 同题同条件。 同一个提示词原样发给三个模型，不追问、不改写。每个模型开新对话，避免历史记录干扰。
  4. 藏起名字打分。 把三份回答复制到一个文档里，标成 A、B、C，过一天再看，按“能不能直接用”“要改多少”“有没有事实错误”各打1到5分。藏名字很重要：知道是哪家写的，你的判断会偏。
  5. 记下成本和时间。 API 用户看后台账单，订阅用户记下等了多久、有没有撞到额度上限。
  6. 得出你的组合。 结果通常不是“一个模型通吃”，而是“写作用 A，代码用 B，批量活用 C”。把它写下来，三个月后用同样的五道题再测一次。

如果不想注册三个海外账号，可以用 OpenRouter 这类聚合平台，一个账号调几十个模型，按量付费，但它同样需要海外支付方式。在国内，可以先在豆包、千问、DeepSeek、Kimi 四个免费应用之间做同样的测试。

五、五个常见的坑

1. 价格表不等于账单。 账单 = token 数量 × 单价。不同模型的分词器不一样，同一段中文切出来的 token 数可能差三成；推理模型的“思考”也算输出 token，开到最高强度，一道题可能多花几倍。Haiku 5.5 就是例子：官方说单价降九成，按实际工作量算约降75%。

2. 跑分不等于你的任务。 发布会上的分数几乎都是厂商自测，挑的是对自己有利的测试集。第23讲会专门讲怎么读基准测试。目前只需记住：分数用来缩小候选范围，最后拍板靠你自己的盲测。

3. 型号换得比你想的快。 9月10日 DeepSeek 用 V4.1 Flash 替换了 V4 Flash，还一度宣布 V4 Pro 的接口名要转到新模型上，后来又改口；谷歌的 Gemini Flash 8月13日出3.7、9月2日又出3.8。做产品时，在代码里写死具体版本号，升级前先用你的测试集跑一遍。

4. 账号和合规风险。 OpenAI、Anthropic、谷歌官方都不向中国大陆提供服务，用海外支付和网络，账号有被封的可能。重要资料不要只存在一个海外账号里；面向国内用户的产品，底层用国内 API 或开放权重模型。

5. 安全限制各家不同。 同样是写网络安全相关的代码，有的模型会直接拒绝。Haiku 5.5 的默认安全策略比上一代更严，渗透测试类请求会被拦下，要申请专门的验证项目才能放开。你的工作如果碰到安全、生物、金融这些敏感领域，测试时要专门放几道这类题。

六、成本：两本账

订阅账（自己用）。 海外三家的入门付费档都在每月20美元左右：ChatGPT Plus、Claude Pro、Google AI Pro。重度档拉开了：Claude Max 从100美元起；谷歌 AI Ultra 5月从250美元降到100美元和200美元两档；ChatGPT Pro 据第三方整理有100、200、500美元三档。国内的豆包、千问、DeepSeek 应用免费。对大多数人，一个20美元的海外订阅加一个国内免费应用，就覆盖了九成需求；什么时候该升到100美元档，看你是不是每周都撞到额度上限。

API 账（做产品）。 用一个具体场景算：每天给1000篇文章写摘要，每篇输入3000 token、输出500 token，一天共300万输入、50万输出。

模型 每天成本 每月（30天）
Claude Haiku 5.5 / GPT-6 Luna 0.30 + 0.25 = 0.55美元 约16.5美元
DeepSeek V4.1 Flash（高峰价） 0.90 + 0.60 = 1.50美元 约45美元
Gemini 3.8 Flash（优惠价） 2.25 + 1.875 ≈ 4.1美元 约124美元
Claude Sonnet 5.5 / GPT-6.1 Sol 6 + 5 = 11美元 约330美元
Claude Opus 5.5 12 + 10 = 22美元 约660美元
GPT-6 Astra / Claude Fable 5.1 30 + 25 = 55美元 约1650美元

同一件事，最便宜和最贵差100倍。摘要是典型的轻活，先用最便宜的一档抽20篇和中端对比，准确率差不多就用便宜的。上面是按标价算的理想值：分词器多切三成、偶尔失败重试，实际账单通常会高一些；反过来，用好缓存和批处理（Anthropic、谷歌的批处理都是五折）又能省下一大块。第5讲专门讲这本账。

适合谁，不适合谁

这套方法适合两类人：每月在 AI 订阅上花钱、想知道钱花得值不值的人；准备做 AI 产品、要在几个模型之间做技术选型的人。它不适合想找“永远的最佳答案”的人：今天的价格表三个月后多半就不对了，留下来的应该是方法：按任务分档，用自己的题测，看脚注算账。

深度长文

一个八岁的孩子，替大人拍后脑勺

Kent Jones《Yi Yi: Time and Space》　Criterion Collection 网站，2011年3月15日；英文，约1700词

肯特·琼斯是美国影评人和导演，拍过纪录片《希区柯克/特吕弗》。这篇是他为 Criterion 版《一一》写的随碟评论。《一一》是杨德昌2000年的作品，拿了当年戛纳最佳导演，也是他的最后一部长片。

琼斯要回答的是：一部从婚礼开始、到葬礼结束、看上去平平淡淡的家庭片，为什么让人觉得装下了整个人生。他的切入点是空间。开头他先讲杨德昌更早的《麻将》里一个镜头：少年的哭声和台北夜景叠在一起。由此引出全文的关键词“诗意的交叠”：声音和画面在场景之间穿过，人物和城市分不开。他还反驳了一个常见说法，即现代都市只会让人疏离：人会把冷冰冰的空间变成私人的地方。

读的时候留意两处。一是他写“孤独中的和声”：父亲 NJ 远在日本见旧情人，女儿婷婷在台北第一次约会，两个人相隔千里，心境却是同一种。二是八岁的洋洋给大人拍后脑勺，理由是“你自己看不到，我帮你看”。琼斯把这一幕当作理解整部电影的钥匙，这几乎也是杨德昌的创作自述。

如果你在跟着系列学摄影，这篇值得配着电影读：同一个镜头里，前景、玻璃反光、远处的楼，都在讲人物。没看过《一一》的，读完这篇再去看，会看见更多。

In Edward Yang's cinema in general, and in Yi Yi in particular, character and environment are inseparable.

（在杨德昌的电影里，尤其是在《一一》里，人物和环境分不开。）

Nearly everyone in Yi Yi acts rashly and impulsively, and everyone is essentially alone.

（《一一》里几乎每个人都冲动行事，每个人本质上都是孤独的。）

阅读范围：全文约10分钟，无需登录，不付费。
