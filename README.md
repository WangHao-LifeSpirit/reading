# 阅读小刊

每天早上一期，约 50 分钟：和你有关的要闻与解析、币市一页、一讲系列课程（艺术史／交易与投资／摄影／AI 工具／音乐，每讲 15—18 分钟），再加一篇值得读的真人好文章。网站：https://read.arthurwanghouse.com

## 它怎么运转

1. 每天清晨，云端定时任务（现在用的是 Claude）按 `编辑指南.md` 出一期，写进 `content/`，运行 `build.py` 生成网页，推送到这个仓库。
2. EdgeOne Pages 发现仓库更新，一两分钟内自动把 `site/` 发布到网站。
3. 每周日晚上，另一个定时任务为下周选好七篇深度长文，放进 `pool/候选池.md`。

两个任务都在云端运行，不需要电脑开机。任务设置里挂着这个仓库，所以能直接推送；怎么检查见 `运维记录.md` 里 9 月 29 日的修复记录。

## 文件

| 文件 | 作用 |
|---|---|
| `编辑指南.md` | 唯一的规则。想改刊物的样子，改这一份就够了 |
| `content/` | 每一期的正文（Markdown，也能直接放进 Obsidian 读） |
| `series/` | 五个系列的大纲和进度，每天接着"下一讲"往下写；网站的"系列"页由它生成 |
| `pool/候选池.md` | 下周的深度长文候选；你想读的文章可以写进"自荐" |
| `pool/来源清单.md` | 深度长文的作者与来源参考 |
| `data/已刊.md` | 已刊清单，用来查重 |
| `logs/` | 每期的核验记录，不上网页 |
| `tasks/` | 两个定时任务的指令原文，以及期刊模板 |
| `更新日志.md` | 给读者看的刊物变化记录，网站的"更新日志"页由它生成 |
| `运维记录.md` | 定时任务、网站部署、事故和验证的内部记录，不上网页 |
| `我的想法.md` | 王昊对这份刊的想法和要求，改版时的依据 |
| `build.py` / `static/` | 生成网页的脚本和样式 |
| `site/` | 生成好的网页，EdgeOne 发布的就是这个文件夹 |
| `edgeone.json` | 告诉 EdgeOne 直接发布 `site/`，不需要构建 |
| `.claude/settings.json` | 预先允许 WebFetch 和 WebSearch，免去逐次确认 |
| `AGENTS.md` | 给接手这个项目的 AI 的说明（`CLAUDE.md` 引用它） |

## 想改点什么

直接跟负责维护的 AI 说就行（现在是 Claude），比如"新闻少一点""多选点电影""这篇不喜欢"。它会改 `编辑指南.md`，第二天起生效。

## 本地和 GitHub

GitHub 上的这个仓库是正本：云端定时任务每天往这里推新刊，网站也从这里发布。电脑上的 `~/Desktop/阅读小刊/reading/` 是它的克隆，文件一模一样，但不会自动更新：要看最新的，先在里面运行 `git pull`；在本地改了东西，要提交并推送回 GitHub，网站和定时任务才看得到。

## 换 AI 或换账号

规则、内容、网站和域名都在你自己的 GitHub 和腾讯云账号里，不绑定任何 AI；绑在 Claude 账号上的只有两个定时任务。换账号或换 AI 时，让新的 AI 先读 `AGENTS.md`，照其中"换 AI 或换账号时怎么接手"一节做。
