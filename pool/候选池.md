# 候选池

每周日晚由选稿任务填好下周一至周日的深度长文（来源参考 `pool/来源清单.md`）；每天出刊时取排给当天的那篇，用过后把状态改成"已用"。王昊自己想读的文章，也可以直接加到"自荐"里，选稿时优先考虑。

每条的格式：

```
### 日期 · 类别（认知/投资商业加密/AI/思想/艺术文学） · 状态（待用/已用/作废）
- 作者、题名：
- 出处与日期：
- 原文链接：
- 阅读范围与时长：
- 访问情况：（是否需要登录/付费，最后核对日期）
- 两句短引（逐字核对过）：
- 按语草稿：（300—450字）
- 语言与登录：（中文/英文；是否需登录 X 等）
- 配图（可选）：图片地址｜作者、作品名、年代、收藏地、授权
```
